# Mission Spark · Learning Experience Generator

אב־טיפוס אישי ל־iFrame של The Zone. הוא מתחיל מעניין ורצון, מציע שלוש משימות, ורק לאחר בחירה חושף למורה את המפה הפדגוגית הסמויה.

## מודל מצב

Personal: הנתונים נשארים בחלון הדפדפן ואינם משותפים בין משתתפים. אין מסד נתונים ואין איסוף מידע אישי.

## מסע

עניין → מה רוצים לעשות → שלוש משימות → בחירה → Need to Know → הנחה → שאלה → בדיקה בעולם → ראיות → המהלך הבא.

## בדיקה ב־Sparkco

הגרסה מיועדת למסגרת iFrame שולחנית ביחס 4:3. הפעולה הראשית נשארת מעל הקיפול, אין ניווט חיצוני, ואין צורך בהרשאות דפדפן.

## מגבלה מכוונת

זהו מחולל מבוסס תבניות ותוכן אצור, לא חיבור חי למודל AI. בשלב הבא אפשר להחליף את פונקציית יצירת המשימות בקריאת שרת למודל, בלי לשנות את מסע המשתמש.

## גרסאות
